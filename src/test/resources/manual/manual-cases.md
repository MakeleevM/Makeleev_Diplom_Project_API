# Ручные тест-кейсы (API)

## TC-M-01. Документация reqres.in
**Шаги:** открыть https://reqres.in/ → Documentation → сверить примеры GET/POST/PATCH/DELETE.  
**Ожидание:** документация доступна и соответствует API.

## TC-M-02. Невалидный x-api-key
**Шаги:** GET `/api/users/2` с `x-api-key: invalid`.  
**Ожидание:** 401 и сообщение об ошибке ключа.

## TC-M-03. Rate limit
**Шаги:** >20 запросов подряд к `/api/users`.  
**Ожидание:** заголовки Ratelimit-* и корректное поведение при лимите.
